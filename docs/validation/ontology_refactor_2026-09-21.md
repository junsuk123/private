# 온톨로지 정책·그래프 모델 개편 검증

검증일: 2026-09-21. Synology 작업 폴더의 변경을 별도 로컬 Git 체크아웃에 복사하여 검증했다. 테스트 저장소는 import 시점부터 임시 디렉터리로 분리했다. 운영 DB를 학습·마이그레이션하거나 브로커 주문을 제출하지 않았다.

## 확인한 실행 연결

- 실제 웹 팩터리가 같은 온톨로지 정책 resolver를 거래 계획, 전략 세션, 공통 판단 엔진, 실시간 감독 루프에 주입한다. 실거래 리스크 매니저는 정책을 필수로 요구한다.
- 필수 근거의 출처·시장·관측 시각·유효 기간·변동성 시간 단위를 검사한다. 선택적 자료 누락과 필수 자료 누락을 구별한다.
- 순수익 기준, 손절·추적 손절, 보유 시간, 조기 탈출 확인, 노출·일일 예산을 생성하고 실제 주문·청산 경로에 적용한다. 보유 후 위험 확대, 중복 관측으로 확인 횟수 충족, 고정 소액 익절, 제출 가격을 실현 손익으로 처리하는 경로를 검사했다.
- 환율 환산, 정수 주문 수량, 브로커 매도 가능 수량 0, 손실 청산 허용, 시세 장애 시 기존 손절 보존을 검사했다.
- OWL/SHACL 형식, RDF 근거 추적, 정책 API, 대시보드의 실제 JavaScript 렌더링·부분 실패·문자열 이스케이프를 검사했다. 실행 가능한 브라우저가 제공되지 않아 실제 화면의 픽셀 검수는 수행하지 못했다.

## 학습 자료와 권한

분봉만으로 과거 온톨로지 정책을 복원하지 않는다. 기존 청산 규칙으로 만든 분봉 라벨은 연구용이며 현재 정책의 실행 권한을 얻지 못한다. 새 전방 가상 평가는 실제 의사결정 전에 포착한 원시 입력 49개, 출처·시각·스냅샷 식별자, 동결 정책, 이후 결과를 연결한다. 모델 입력 72개는 이 원시 입력에 전략 식별자 23개를 붙인 것이다.

온톨로지 정책으로 진입 시 동결한 가상 청산과 이후 정책이 변하는 실제 청산은 서로 다른 평가 계약이다. 가상 평가로 검증된 그래프는 제한된 위험 보조 신호만 제공하며 직접 주문 권한은 부여하지 않는다. 위험 보조 신호가 시장 관측만으로 생성한 손절·자금 한도를 완화하지 못하도록 별도 검증한다. 미관측 전략의 결과는 학습 마스크로 제외한다.

KR/US 검증 구간은 시장별로 유지하되 공유 가중치의 학습 자료는 두 시장 중 가장 이른 검증 시작보다 앞에서 종료되어야 한다. 미래·중복·미완결 결과, 다른 정책·시장·출처, 훼손된 모델 파일은 승격 근거가 아니다. 검증 실패 후보는 기존 검증 모델을 덮어쓰지 않는다.

## 검증 결과와 한계

최종 전체 회귀 테스트: **3,862 passed, 5 subtests passed**, 258.02초. FastAPI·Starlette·RDFLib의 기존 폐기 예정 API 경고 111건이 있으며 실패는 없었다. Windows / Python 3.13에서 `python -m pytest -q --tb=short`로 실행했다.

Python 컴파일과 JavaScript 구문 검사를 통과했다. wheel 내 TTL/SHACL·화면 자산·새 학습 모듈 7개 항목의 포함 여부를 확인했다. Git에 포함할 73개 파일이 작업 폴더와 일치하며 자격증명·운영 DB·운영 모델·로그를 포함하지 않는 것도 확인했다.

[Intel NPU 실측](temporal_rgcn_benchmark_2026-09-20.json)은 합성 데이터 기반 전체 그래프 추론의 중앙값 1.253ms, p95 1.653ms였다. 이는 거래 API 지연이나 실거래 수익률의 측정값이 아니다. NVIDIA GPU 두 환경의 실제 장치 성능은 이번 실행에서 측정하지 않았다.

전략과 모델의 수익성은 시장별 실제 시세·비용·시간 순서 검증으로 계속 확인해야 한다. 이 변경은 운영 연결·데이터 계약·손실 통제의 검증이며, 모든 시장에서 수익을 보장하는 결과가 아니다.
