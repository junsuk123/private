# 시간 인식 관계형 그래프 모델

2026-09-20 변경. 채택한 구조는 **작은 시간 인식 R-GCN**(`time_aware_rgcn_v1`)이다. 원래 TGAT를 구현했다고 부르지 않는다. 실제 시장 수익률 비교 실험에서 이겼다는 주장이 아니라, 현재의 적은 학습 자료·국장/미장 관계 분리·Intel NPU 정적 연산·업데이트 비용을 기준으로 선택했다.

## 검토와 선택

| 후보 | 장점 | 현재 시스템에서의 비용과 한계 | 결정 |
| --- | --- | --- | --- |
| R-GCN | 관계 종류마다 다른 변환으로 온톨로지 관계를 표현한다. 조밀한 고정 크기 행렬곱으로 배포하기 쉽다. | 기본 구조는 실제 시간 간격을 표현하지 않는다. | 관계형 인코더로 채택하고 인과적 시간 가중치를 추가했다. |
| R-GAT | 관계와 이웃별 학습 attention으로 메시지 중요도를 조절할 수 있다. | attention 학습과 정규화가 추가된다. 적은 표본에서 우월하다는 근거가 없고, 원 논문도 R-GCN 대비 일관된 우위를 보고하지 않았다. | 기본 배포 모델로 채택하지 않았다. |
| 시간 인식 GAT/TGAT | 시간 인코딩과 attention으로 불규칙한 시간 그래프를 다룬다. | 동적 이웃 표본 추출·시간 인코딩·attention을 모두 작은 정적 NPU 입력으로 맞추는 추가 비용이 있다. | 구현 복잡도와 표본 요구량을 고려해 보류했다. |

원문: [R-GCN 논문](https://arxiv.org/abs/1703.06103), [R-GAT 논문](https://arxiv.org/abs/1904.05811), [TGAT 논문](https://arxiv.org/abs/2002.07962). 사용자가 적은 Ta-GAT는 특정 논문 식별자가 없어 시간 인식 GAT 계열로 해석하고 대표 논문 TGAT를 검토했다. 금융 시장에서 세 구조의 수익률 우열을 증명한 실험은 수행하지 않았다.

## 실제 구현

- 기존 전략 효용 그래프의 현재 스키마 학습과 실시간 서비스에 연결했다. 국장/미장 적용 범위가 다른 전략은 서로의 그래프에서 메시지를 보낼 수 없다.
- 23개 전략 노드, 3개 관계, 노드당 72개 입력, 은닉 16개, 최근 3개 분 관측을 사용한다. 관계 축은 OWL `pol:sameMethodologyFamily`, `pol:confirmsStrategy`, `pol:contrastsStrategy`와 일치한다.
- 현재 관측 시각을 기준으로 미래·다른 종목·10분 초과·비정상 관측을 제외한다. 실제 경과 시간을 반감기 120초로 감쇠하고 존재하는 관측끼리 정규화한다. 120초/10분은 시장 주문 임계치가 아닌 버전 관리되는 모델 입력 계약이다. 같은 분의 중복 tick은 표본 수를 부풀리지 않는다.
- 학습과 추론이 같은 시간 창 생성기를 사용한다. 전략 진입 허용 여부는 최종 출력 마스크에 반영한다. 이전처럼 학습 때와 실시간 때 그래프 연결 자체가 달라지지 않는다.
- **관계 가중치, 자기 노드 변환, 전략 출력, 거래 대기 출력 모두 저장하고 추론한다.** 고정 난수 그래프를 학습 모델로 표시하지 않는다. 현재 모델은 8,672개의 학습된 파라미터를 갖는다.
- NPU 컴파일은 작업 스레드에서 수행한다. 준비 중이거나 장치 오류가 있으면 동일한 학습 가중치로 NumPy 추론한다. OpenVINO 그래프에는 모든 관계·시간·출력 연산이 들어가고 전체 원시 출력의 수치 일치를 검사한다. 장치별 연산 지원은 [OpenVINO NPU 문서](https://docs.openvino.ai/2026/openvino-workflow/running-inference/inference-devices-and-modes/npu-device.html)와 실제 장치 실행으로 확인했다.

## 학습과 승격

각 시장의 최근 2,048개 스냅샷을 기본 재생 범위로 사용한다. 기본 12 epoch·최대 128회 gradient 갱신이고 환경변수 값에도 상한이 있다. 국장과 미장 holdout을 각각 시간 순서로 나누며, 각 표본의 실제 label 종료 시각과 60초 embargo가 검증 시작보다 앞서야 학습에 포함한다. 두 시장은 같은 학습 파라미터를 쓰므로 **가장 이른 시장 holdout 시각 이후의 타 시장 자료도 학습에서 제외**한다. purge 후 자료가 없어졌다고 누수 표본을 복원하던 기존 fallback을 제거했다. holdout을 학습에 재투입하지 않는다.

상승 사례 학습 여부와 승격에 필요한 표본 수는 **학습 구간의 관측된 결과만** 센다. 양성/음성 표본에 동일한 Bernoulli 손실을 적용해 드문 수익 사례의 확률을 임의로 부풀리지 않는다. 누락된 전략은 그래프 노드만 유지하고 모든 학습 채널을 마스킹한다. 알려진 수익 사례가 없다는 이유만으로 관측되지 않은 대안까지 거래 부적합이라고 학습하지 않는다. 이미 검증된 보조 모델의 시장 권한을 잃는 후보, 또는 정책이 연결된 모델을 대체하려는 과거 분봉 연구 모델은 `.candidate.npz`에 보관한다.

라벨 계약은 두 가지다. 과거 분봉의 `legacy_strategy_geometry_v1`은 기존 청산 구조의 연구용 반사실 결과이며 현재 온톨로지 정책을 검증하지 않는다. `ontology-risk-v1-entry-frozen-shadow`는 당시 실제로 저장된 원시 49차원 문맥·특징 식별자·온톨로지 정책·진입 계획과 이후 Shadow 결과가 정확히 연결된 경우만 생성한다. 72차원 노드 입력은 이 49개 특징에 23개 전략 식별자를 더한 값이다. 과거 온톨로지 문맥을 만들어 채우지 않는다.

두 번째 라벨도 **진입 시 고정한 청산 장벽의 Shadow 결과**이며 보유 중 정책이 변경되는 실거래 수익 검증은 아니다. 관측된 학습 결과 1,000개 및 서로 다른 학습 시점 1,000개, 시장별 검증 표본·종목 다양성·순수익 신뢰구간·순위 검증을 통과해야 해당 시장의 제한된 위험 보조 권한만 부여한다. `live_authorized`는 항상 false이며 이 모델 자체는 주문 권한을 부여하지 않는다. 과거 tick 기반 GNN 신뢰 평가도 기존 청산 구조에 대한 연구 보정 통계로 표시하며 실거래 진입 권한을 만들지 않는다.

시장 단위 검증만으로 다른 전략의 미학습 출력을 승인하지 않는다. 보조 증거로 선택하는 각 전략은 해당 시장의 학습 구간에서 양수·음수 순수익 결과가 각각 20개 이상 있어야 하며, 다른 시장의 표본이나 누락된 결과를 그 수에 넣지 않는다.

`ShadowIntelligenceService.latest_graph_advisory(symbol, as_of)`는 계약과 시장 검증을 통과한 신선한 결과만 반환한다. 불확실성과 진입 시 고정한 정책의 조건부 순손실 추정은 위험을 강화하는 보조 자료로만 사용한다. 일반적인 현재 정책의 예상 순수익·성공 확률 필드를 내보내지 않고 라벨 계약과 `bounded_risk_advisory_only` 범위를 명시한다. 모델이 없거나 검증되지 않았으면 `None`을 반환한다. 불확실성은 학습된 대용 지표이며 Bayesian epistemic uncertainty를 계산했다는 뜻이 아니다. 기존 효용 모델의 MAE/MFE 이름은 실제 경로의 최대 역행/순행이 아니라 조건부 순손실/순이익을 뜻하므로, 정책 연결에서는 `expected_downside_net_bps`로 표시한다.

체크포인트 기본 위치는 기기별 `runtime_database_path("models/strategy_utility/temporal_rgcn.npz")`다. `REFACTOR_GNN_CHECKPOINT`로 명시적으로 바꿀 수 있다. 기존 1시점 체크포인트는 기존 계약으로만 읽으며 새 시간 인식 정책 증거로 취급하지 않는다. 학습 CLI도 기기별 실시간 DB와 같은 모델 경로를 사용한다.

기존 웹 백그라운드 학습 루프는 그래프 갱신 작업도 자동 예약한다. 기본 주기는 900초이며 동시에 하나만 실행한다. 먼저 `DIRECTIONAL_SHADOW_STORE_PATH`의 실제 정책·Shadow 결과 연결 라벨을 최대 4,096건 읽고, 신규 결과가 완성된 스냅샷이 64개 이상이면 우선 학습한다. 이미 학습한 계획·정책·특징·결과 식별자는 재학습 신규 건수로 세지 않는다. 이 자료가 부족하면 로컬 분봉 DB에서 시장별 최근 8개 종목·종목별 완료된 720개 분봉을 읽기 전용 임시 DB에 복사해 **연구용 모델만** 학습한다. 종목별 데이터 진행 및 시장별 학습 시각을 별도로 추적한다. `AUTO_TRAIN_TEMPORAL_RGCN=false`로 자동 갱신을 끌 수 있으며, 학습은 시세 처리 스레드에서 실행하지 않는다.

체크포인트와 검증 보고서를 각각 원자적으로 기록하며 해시가 일치하는 쌍만 읽는다. 서비스는 별도 작업 스레드에서 15초 이상 간격으로 변경을 확인하고 구조·해시·기존 시장 권한 보존 여부를 검사한 뒤 전체 학습 파라미터를 교체한다. 교체 시 이전 보조 예측은 폐기한다. 부분 기록·손상·검증 실패는 기존 모델을 유지하며, 새 모델의 NPU 컴파일이 끝나기 전에도 동일한 학습 파라미터로 CPU 추론할 수 있다. 이 작업에서는 실제 운영 DB 학습이나 운영 모델 승격을 실행하지 않았다.

## 검증

[실측 JSON](validation/temporal_rgcn_benchmark_2026-09-20.json): Intel Core Ultra 7 155H / Intel AI Boost, OpenVINO 2026.3.1, 전체 모델 NPU 추론 100회 중앙값 **1.253ms**, p95 **1.653ms**, 초기 컴파일 **1.769초**. NumPy 대비 전체 원시 출력 최대 절대 오차 **0.00198**, 적용 가능한 전략의 예상 순수익 최대 오차 **0.00350bps**였다. 64개 합성 스냅샷의 학습은 12회 갱신에 약 **2.71초**였다.

이는 **합성 데이터로 학습한 모델의 장치/수치/지연 검증**이다. 실거래 수익률, 거래 API 왕복 지연, RTX 장치 성능을 나타내지 않는다. 실제 비용 차감 holdout을 통과한 운영 모델은 이 작업에서 만들거나 승격하지 않았다.

재현: `python scripts/benchmark_temporal_rgcn.py --device NPU --iterations 100 --output result.json`. 이 스크립트는 임시 체크포인트만 생성하고 브로커나 운영 모델 저장소에 접근하지 않는다.
