# 다중시장·경량 추론 리팩터링 — 2026-09-20

국장과 미장의 데이터 수집·판단을 독립시키고, 실제 주문에 도달하지 못하던 연결 오류를 수정했다. 수익을 만들기 위해 안전 기준을 완화하는 대신, 검증된 데이터·비용 차감 기대수익·현금·주문 가능 시간을 일관되게 사용한다. 모든 시장에서 매수하는 시스템은 아니다. 불명확하거나 비용을 감당하지 못하는 상태에서는 현금 대기가 정상 출력이다.

## 실행 구조

```text
KIS 단일 WebSocket
  ├─ 국장: 국내 TR / KRX·NXT 데이터
  └─ 미장: 해외 TR / 세션별 구독 키
      ↓ 메모리 이벤트 큐 · 비동기 저장
  KR 맥락·전략           US 맥락·전략
      └─ 출처·발표시각·시장 적용 관계 그래프
                  ↓
  시장별 전략 평가 → 비용·손실·수량 검증 → 거래 계획
                  ↓
  현금 롱 진입 / 보유 청산 → 최종 주문 가능성·중복 확인
                  ↓
  기존 KIS 주문 어댑터

기기 로컬 학습 DB → 제한된 비선형 학습 → 시간 분리 검증
                      ↓ 통과한 모델만 원자적 교체
                NPU / CUDA / CPU 추론
```

같은 API 키로 국내·해외 WebSocket을 두 개 여는 대신 한 연결에서 서로 다른 TR을 구독한다. 시장별 평가 순서를 교차하고 구독 예산은 공유한다. 보유 종목을 우선 유지하며 구독 순서를 실제 전송에서도 보존한다. 종료·취소 때 구독을 해제하고, 종목 탐색은 수신 루프 밖에서 수행한다. 두 시장을 동시에 관찰할 수 있어도 현재 계좌 실행기는 하나의 소유 전략·신규 진입을 순차 처리한다.

## 변경 내용

| 요청 영역 | 반영 |
|---|---|
| NPU 우선 | 고정 형태의 작은 ReLU 모델, 가중치 식별 캐시, 백그라운드 컴파일, 실제 장치/전환 사유 표시 |
| Windows GPU / Linux GPU | CUDA 별도 실행 경로, 장치 부재·오류 시 CPU 계산. GPU 설치가 LLM 설치를 자동 유발하지 않음 |
| 국장·미장 구분 | 맥락, 세션, 시장 폭, 업종, 레짐 이력, 전략 설정을 각각 계산 |
| 관계 그래프 | 지표 출처·실제 관측시각·원시장·대상시장·유효기간을 보존, 부적절한 연결 배제 |
| 롱 중심 전략 | 시장별 추세·범위·회복·하락 상대강도 전략 우선순위, 불명확/스트레스 상태 현금 선호, 실운영 신규 주문 현금 롱 제한 |
| 손실 관리 | 일일 금액/비율 한도 중 작은 값 적용, 국장 15%·미장 12% 상한, 1주 올림으로 상한 초과 불가, 손실 청산 허용 |
| 최소 학습 | 제한된 DB 표본·업데이트 횟수, 데이터 불변 시 생략, 무거운 temporal GNN 자동 학습 기본 중지 |
| GUI | `/account`에 손익·두 시장·첫 차단 원인·주문·실제 추론 상태. 기존 기능 `/account/advanced` 유지 |
| 동기화 환경 | 활성 모델·학습 DB·장치별 바이너리 캐시는 기기 로컬에 저장. 충돌 사본은 보존하고 자동 테스트 수집에서 제외 |

시장별 자금은 통화를 보존한다. 원화 잔액으로 달러 매수가 가능하다고 추정하지 않으며, 증권사가 반환한 주문 가능 금액 0을 다른 잔액으로 덮어쓰지 않는다. 최종 주문 수량이 최신 주문 가능 수량을 초과하면 원래 수량을 보내지 않는다.

일일 손실 검사는 사이클과 전략 감독자가 같은 통화·같은 한도를 사용한다. 평가액이나 필요한 환율이 없으면 신규 진입을 보류한다. 검증된 청산은 신규 투자용 현금 유보율과 비중 제한에서 제외하되, 실제 매도 가능 수량과 매수 청산에 필요한 현금은 계속 검사한다.

시장 프로필의 `CASH`는 현금 대기 권고다. 그 값 자체가 주문을 금지하거나 허용하지 않는다. 실제 신규 진입은 종목별 온톨로지, 비용 차감 기대수익, 데이터 신선도, 계좌 위험과 세션 권한 검사를 모두 통과해야 한다. GUI의 세션 가능 여부와 전략 권고도 이 의미로 구분한다.

## 확인된 오류

- 국장·미장 알고리즘/명세 설정을 공통 인스턴스 하나로 재사용하던 오류.
- 미국 종목에 한국 시장 맥락을 붙이고 그래프의 한국 시장 노드에 기록하던 오류.
- 일부 전략의 온톨로지 분류 누락과 개장 후 경과 시간 입력 누락.
- 과거 지표를 현재 시각으로 표시하거나 0인 시장 폭을 결측으로 처리하던 오류.
- NPU 캐시가 바뀐 가중치를 구분하지 않고 CPU 전환을 NPU 실행처럼 보고하던 오류.
- 모델 검증에서 실제 레이블 종료 시각보다 짧게 데이터 구간을 제거하던 오류.
- 시장 대비 초과수익을 실제 순수익으로 학습하던 오류.
- 일부 주문 경로에 주문 가능 현금·매도 가능 수량 공급 함수가 빠진 오류.
- 계좌 캐시가 오래되어도 최신 데이터처럼 표시되던 오류.

## 실행과 확인

Windows에서는 기존 `setup.ps1`, `run.ps1` 진입점을 유지한다. Intel NPU 패키지는 `./setup.ps1 -WithNpu`로 설치할 수 있다. NVIDIA 환경은 자동 감지하면 `cuda` 추가 의존성을 설치하며, 필요한 CUDA wheel 저장소는 기존 `-CudaWheels` 옵션을 사용한다. Linux도 기존 PowerShell 실행 흐름과 `.venv-linux`를 유지한다. 가상환경은 OS 간 복사해서 쓰지 않는다.

`run.ps1`은 기존과 같이 실거래용 실행 플래그를 설정한다. 단순 테스트·추론 성능 측정에는 서버를 실행할 필요가 없다.

```powershell
.venv/Scripts/python.exe -m pytest tests -q --disable-warnings
.venv/Scripts/python.exe scripts/benchmark_adaptive_runtime.py --help
```

현재 장비의 실제 Intel AI Boost NPU에서 100회 합성 추론을 측정했다. 중앙값 0.620ms, p95 0.719ms, 최초 컴파일 547.349ms였다. 전체 거래 지연이나 투자 수익을 측정한 값은 아니다. [측정 JSON](validation/adaptive_runtime_benchmark_2026-09-20.json)과 [모델 설명](adaptive_signal_runtime.md)에 재현 방법을 기록했다. RTX 4060/5060과 Linux의 실제 장치 성능은 이번 장비에서 검증하지 못했다.

기존 동기화 모델은 삭제하지 않았다. 새 기기 로컬 레지스트리는 해당 기기의 검증된 학습 결과로 채워진다. 경로는 `REALTIME_STORE_ROOT`, `LIVE_MODEL_ARTIFACT_ROOT`로 지정할 수 있다. 이미 설정한 환경변수는 기본값을 덮어쓸 수 있으므로 운영 중인 프로필을 확인한다. 같은 계좌를 여러 PC에서 동시에 실행하는 분산 주문 리더 선출은 구현하지 않았다. 실제 주문 담당은 한 프로세스로 운영해야 한다.

## 검증 범위와 남은 제약

최종 회귀 검증: 개인 설정이 없는 GitHub 게시용 작업 사본에서 `python -m pytest tests -q --disable-warnings --maxfail=10 --tb=short` 결과 **3,599개 통과, 하위 사례 5개 통과, 실패 0개**였다(276.82초). 경고 111개는 남아 있다. Python 소스·스크립트 컴파일, 화면 JavaScript 문법, PowerShell 런처 구문, `uv lock --check`도 통과했다. Synology의 과거 `*_Conflict.py` 사본은 정식 테스트 대상에서 제외했다.

게시 검증 과정에서 지정가 전용 예제 설정의 시장가 허용 값을 수정하고, 관련 테스트가 개인 운영 설정 대신 추적되는 예제를 명시적으로 사용하도록 정리했다. 실제 운영 설정 파일이 누락되면 명시적 예제 사용 허용 없이는 계속 거부하는 기존 동작을 유지한다.

이번 작업에서 실주문·서버 자동 시작·계좌 설정 변경은 실행하지 않았다. 자동 테스트는 외부 네트워크 연결을 막고, 저널·모델·런타임 DB를 임시 경로로 분리한다. JavaScript 실행과 문법은 검증했지만 브라우저 도구가 제공되지 않아 실제 화면의 시각 검사는 수행하지 못했다.

일부 거시 지표는 일별 또는 저빈도 자료다. 실시간 호가와 같은 신선도로 취급하지 않는다. 로컬 지수 방향은 추적 종목군의 대용 지표이며 거래소 공식 지수 그 자체가 아니다. 존재하지 않는 유료 지표 구독을 새로 연결했다고 표시하지 않는다. 장외·NXT 실주문은 기존 증권사 capability와 실제 계좌 권한을 통과해야 하며, 거래 시간표만 보고 권한을 활성화하지 않는다.
